# Placement Portal Application V2

A full-stack web application for managing campus placement activities.

## Roles
- **Admin** – Approves companies and placement drives, manages all users
- **Company** – Posts placement drives, reviews and shortlists applicants  
- **Student** – Browses drives, applies, tracks application status

## Tech Stack
- **Backend**: Flask, SQLAlchemy, Flask-JWT-Extended
- **Frontend**: Vue.js (CDN), Bootstrap 5
- **Database**: SQLite
- **Cache**: Redis
- **Jobs**: Celery + Redis

## Setup Instructions
```bash
cd backend
pip install -r requirements.txt
python app.py
```
